# HDRP Viewmodel

[![Unity 2022.3+](https://img.shields.io/badge/unity-6000.3%2B-blue.svg)](https://unity3d.com/get-unity/download)

This package provides a custom pass to draw your 3D viewmodel on top of the world with HDRP, wrapped in a convenient component.
